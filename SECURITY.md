# Security

Please report vulnerabilities privately through GitHub's "Report a vulnerability" button on this repository (Security tab), not in public issues.

Useful reports include: a way for page content or a model to read vault values, to pay without the user's approval or for a different total, to use another install's hosted browser or profile, or to read the hosted service's provider key.

The threat model and its limits are described in the README under "Security model, honestly".
